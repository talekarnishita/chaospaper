## Suggested order of work

1. **Methodology (P1)** – Add parameters table and flowchart; align Abstract/Introduction/Methods with the pipeline. Use README_TECHNICAL and README as sources.
2. **Data (P2)** – Add data sources, N, and dataset description; address NBA “no chaos” and small-N limitations in Results and Discussion.
3. **Hypothesis (P3)** – Add counterexamples subsection and forecasting comparison (chaotic vs stochastic vs baseline).
4. **Theory (P4)** – Clarify feature engineering (composite vs per-metric); add sensitivity and alternatives.
5. **Practical (P5)** – State limitations; extend forecasting to more teams and compare to baseline.
6. **Documentation (P6)** – Explain Eq. 2; add flowchart figure; state Keenan/short-series limitations.
